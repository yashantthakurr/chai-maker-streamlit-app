# ☕ Chai Maker – Tea Ordering & Billing App

Chai Maker is a Streamlit-based web application that simulates a real café tea ordering and billing system.

## 🚀 Features
- Dynamic tea & garnishing menu with prices
- Input validation using Streamlit session_state
- Multi-page navigation (Order → Summary)
- Price breakdown per cup
- Total bill calculation
- PDF bill generation and download
- Clean and user-friendly UI

## 🛠 Tech Stack
- Python
- Streamlit
- ReportLab

## ▶️ How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
